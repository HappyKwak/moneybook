데이터는 브라우저 localStorage에만 저장됩니다.

- 대분류: 데이트 / 개인 (대출은 대출 탭에서 따로 관리, 가계부 합계엔 안 들어감)
- 데이트는 결제자(나/여자친구)별 집계 — 여자친구가 낸 건 내 지출 합계에서 빠짐
- 고정비 별도 관리, 월 총액에 합산 (고정비도 나라 선택, 유로 고정비는 오늘 환율로 환산)
- 원화/유로 입력 (ECB 환율 자동 갱신)
- 나라별 보기: 원화 = 한국, 유로 = 독일. 내역·통계에서 전체/한국/독일 필터
